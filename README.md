# TermVisualization-BGA-

3D-визуализация модели БГА и температурных датчиков на Panda3D.

## Данные

- STL-модель: `data/model.stl`.
- Датчики: `data/sensors.csv` со столбцами `id,x,y,z,temperature`.
- Координаты датчиков должны быть в той же системе координат и единицах,
  что и STL. Приложение центрирует и масштабирует модель и датчики вместе.
- Количество датчиков определяется числом строк данных в CSV. Если CSV
  отсутствует, приложение создаст демонстрационный файл со 102 точками в
  габаритном объёме модели.
- В боковой панели можно менять прозрачность модели и просматривать таблицу
  температур датчиков по ID.

## Запуск на macOS

Из корня репозитория выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```
